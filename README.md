# AskMyDocs

**RAG-powered document Q&A system built with LangChain for intelligent information retrieval.**

## Repository Visibility

**No, this repository is NOT private to you only.**

This repository is currently set to **PUBLIC**, which means:
- ✅ Anyone on the internet can see this repository
- ✅ Anyone can clone and fork this repository
- ✅ All code, commits, and documentation are publicly accessible

### How to Make This Repository Private

If you want to make this repository private (visible only to you and collaborators you explicitly grant access to):

1. Go to your repository on GitHub: https://github.com/harii55/AskMyDocs
2. Click on **Settings** (top right of the repository page)
3. Scroll down to the **Danger Zone** section
4. Click on **Change visibility**
5. Select **Make private**
6. Follow the confirmation prompts

### Privacy Considerations

Before making your repository private, consider:
- **Public repositories** are great for open-source projects and building your portfolio
- **Private repositories** are better for:
  - Proprietary code
  - Projects containing sensitive information
  - Code you're not ready to share publicly
  - Personal projects with API keys or credentials (though these should never be committed!)

## About AskMyDocs

This project aims to create an intelligent document Q&A system using:
- **RAG (Retrieval-Augmented Generation)** for accurate, context-aware responses
- **LangChain** framework for building LLM applications
- Document processing and semantic search capabilities
